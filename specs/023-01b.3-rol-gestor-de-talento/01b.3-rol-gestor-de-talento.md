# 01b.3 · Nombre del rol «Gestor de Talento»

Función: inc-01b Ajuste de categorías y parámetros · Semana 3 del plan (26–30 oct) · Origen: Técnica · Depende de: —

## Contexto
Las pantallas y textos de categorías usan el nombre anterior «Administrador de Talento Humano». El documento de alcance del proyecto llama a ese rol «Gestor de Talento», y el nombre anterior se confunde con el Administrador técnico que registra empresas.

## Usuarios
- Todos los roles del módulo.

## Historias de usuario
- Como usuario, quiero ver el rol con el nombre «Gestor de Talento» en todo el módulo, para que coincida con el alcance del proyecto.

## Criterios de aceptación
- CA-01. Todas las pantallas, textos, mensajes y avisos del módulo dicen «Gestor de Talento»; no aparece «Administrador de Talento Humano».
- CA-02. En el repositorio de prueba, los permisos de Gestor se conceden al rol Administrador existente; no se crea un rol nuevo ni se renombra un rol del sistema.
- CA-03. Los permisos del módulo se nombran recurso.acción.
- CA-04. Las pruebas existentes de inc-01 siguen pasando.

## Fuera de alcance
- Cambiar nombres de roles en otros módulos.
- Crear roles nuevos.
