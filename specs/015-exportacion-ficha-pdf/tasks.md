## Phase 5: User Story 3 — Progreso, errores y entrega segura (Priority: P2)

## Estrategia

MVP = Setup + Foundational + US1 (el Administrador exporta una ficha). Entrega incremental: US2 (propia con permiso independiente) → US3 (fallos, revocación y coherencia) → E2E, volumen y pulido. Tras cada historia, ejecutar sus pruebas Pest/Vitest. La instalación de dompdf (T001) es el primer paso real de la implementación; si falla en PHP 8.5, se detiene y se decide la contingencia antes de continuar.
