## Estrategia

MVP = Setup + Foundational + US1 + US2 (el Administrador prepara y publica una política con parámetros válidos). Entrega incremental: US3 (versiones, vigencia, retiro y comparación) → US4 (fachada y consulta de condiciones, contrato de consumo) → US5 (plantilla de offboarding) → E2E, volumen y pulido. Tras cada historia, ejecutar sus pruebas Pest/Vitest. Las pruebas demuestran el comportamiento del sistema; la validez de las reglas para la organización se revisa además con el cliente mediante casos de negocio. Esta funcionalidad no implementa los procesos de novedades, movimientos ni offboarding: solo define su contrato de consumo.
