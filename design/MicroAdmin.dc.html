Micro-learning

Repositorio de cápsulas breves (videos, PDF, artículos y quizzes) asociadas a competencias.

Ver como colaborador

Úsalo para conocimientos, no para conductas. El e-learning es eficaz para transmitir conocimientos pero no para desarrollar competencias conductuales (Alles, Herramienta N° 17, p. 125–126). Por eso cada cápsula se etiqueta como «Apto para conocimientos». Para competencias blandas, combínalo con capacitación presencial, OJT, codesarrollo o mentoring del Plan anual.
